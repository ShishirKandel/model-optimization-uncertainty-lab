How to read this chart

The solid line shows mapped area up to 2023. The square is the observed 2024 area; the blue point is the chosen model’s forecast. The vertical blue band represents its nominal 90% prediction interval, which can miss the observation. Forecast areas are calculated from the 2023 area and the model’s predicted proportional change. Missing historical years are not interpolated.

Classification results and metric definitions

MAE and RMSE measure error in proportional area change: 0.10 is ten percentage points. Coverage is the fraction of observations inside nominal 90% intervals. Interval score balances width and misses. For classifiers, lower Brier score and log loss are better; higher average precision indicates better expansion ranking.

Controller method and limits

This demo uses the original hand-designed membership sets and 15-rule table with the current input guard. Mamdani inference uses minimum for conjunction and implication, maximum for aggregation, and a centroid over 201 output points. Negative commands mean cooling; positive commands mean heating. There is no room-dynamics simulation here.

The report also evaluates genetic membership tuning. Its 74.2% reduction in synthetic-policy command error does not establish better room-temperature tracking. A separate plant-consistent study is documented in the Task 2 report. The live controller on this page is the manual baseline.

A valid manual command has priority. Nonfinite or invalid inputs return a zero command with a fault status; finite inputs outside the declared domains are clipped. Software limits are not evidence of occupant safety.

The work behind the interface.

Two tasks, two different questions

Task 1 studies probabilistic forecasts of annual glacial-lake area change in Nepal. This interface exposes the saved 2024 evaluation across 478 lakes, with five regression models and three classifiers.

Task 2 studies fuzzy control and evolutionary optimisation for an assistive-bedroom HVAC system. The interface lets you inspect the manual controller’s actual rule-based computation.

What is running here?

The lake explorer reads exported results from the completed Python experiments. The room controller runs a JavaScript implementation checked against the Python controller. Neither tab retrains models. All interactive assets are bundled with this site.
